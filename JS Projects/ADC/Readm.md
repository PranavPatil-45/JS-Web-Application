
# 🛒 Simple Add to Cart Web App

This is a basic "Add to Cart" web application built using **HTML**, **CSS**, and **JavaScript**, with product data fetched from the [Fake Store API](https://fakestoreapi.com/).

It displays a list of products, allows users to add them to a shopping cart, and shows cart contents with images and quantity.

---

## 🚀 Features

- ✅ Fetches products using a public REST API
- 🖼️ Displays product image, title, and price
- 🛒 Adds items to cart with quantity management
- 📷 Cart shows item image, name, and quantity
- 💡 Clean and beginner-friendly code

---

## 🔧 Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- [FakeStoreAPI](https://fakestoreapi.com/) for product data
